## 作業手順

### Step 1. 管理画面へログイン（2 分）

1. ブラウザで `https://column.namae-studio.com/kodomo-login/` を開く
2. 管理者アカウントでログイン

> ログイン URL が `/wp-login.php` ではなく `/kodomo-login/` なのは SiteGuard で変更済なので注意じゃ（参照: [plans/wp-install-handoff-2026-04-20.md](wp-install-handoff-2026-04-20.md) § セキュリティ）。

---

### Step 2. 巨大な AFFINGER4 ロゴを消す（5 分）

スクリーンショット中央の「AFFINGER4」という赤い巨大ロゴは、AFFINGER4 デフォルトの **ヘッダー画像** または **トップページ用メインビジュアル**。以下どちらかの箇所にある。

#### 2-1. ヘッダー画像の可能性（大半はここ）

1. 左メニュー **外観 → カスタマイズ** を開く
2. 左パネルの **「ヘッダー画像」** を開く
3. 「現在のヘッダー」に AFFINGER4 ロゴ画像があれば **「非表示」** または **「削除」**
4. 上部の「公開」ボタンで保存

#### 2-2. AFFINGER4 管理のロゴ設定の可能性

1. 左メニュー **AFFINGER 管理 → ヘッダー** を開く
2. 「ヘッダーロゴ画像」「トップページのヘッダー画像」「モバイルのヘッダー画像」等の欄を確認
3. 不要な画像 URL を空にするか、「使用しない」チェックを入れる
4. 「Save」で保存

#### 2-3. 代わりにサイト名テキストを表示

1. **外観 → カスタマイズ → サイト基本情報**
2. 「ロゴを選択」を使わず、「サイトのタイトルとキャッチフレーズを表示」にチェック
3. サイトタイトル: `子供の名付け診断コラム`（既設定）
4. キャッチフレーズ: `赤ちゃんの名付けを楽しく学ぶコラム`（既設定）
5. 公開

> 自作ロゴを使う場合は `assets/images/logo-icon.png`（親サイトロゴ、40×40px）を流用しても良い。必要なら別途プラン化。

---

### Step 3. Google+ 等の古い SNS ボタンを非表示（5 分）

**調査結果**: AFFINGER4 の SNS 設定には **サービス別のトグルが無い**（全てオン/オフの粒度のみ）。よって以下の方針に変更する。

1. **AFFINGER4 管理** の SNS 設定セクションを開く（`admin.php?page=my-custom-admin#sns-m`）
2. 右パネル「SNS 設定」で:
   - [x] **トップページのSNSボタンを非表示にする** ← チェックする
   - [ ] 投稿ページのSNSボタンを非表示にする ← **今は保留**（記事流入前に再判断。Google+ 終了問題があるので「絶対必要」とユーザー認識済み）
   - [ ] SNSボタンを固定ページでも表示する ← チェックしない
3. **save** で保存

> 投稿ページ側の SNS ボタン処理は「絶対に必要だが今回は保留」という意思決定。記事自動投入が動き始める前に必ず対応すること。Google+ を個別に消すには CSS 追加（子テーマ案件）か AddToAny 等のプラグイン差し替えが必要。

---

### Step 4. サイドバーウィジェットを整理（8 分）

スクリーンショットのサイドバーは「新しい記事はありません」「検索」「最近の投稿（空）」「最近のコメント（空）」が並んでおる。ほぼ全部差し替える。

**WP 6.x 以降はブロックエディタ式ウィジェット画面** になっておる点に注意。旧来の「ドラッグ＆ドロップ」ではなく、**ブロックをクリック選択 → 三点メニュー（︙）から削除 or `+` ボタンから追加** という操作になる。

#### 4-1. 不要ブロックを削除

1. **外観 → ウィジェット** を開く
2. 「サイドバーウィジェット」アコーディオン内で、以下のブロックを **1 つずつクリックして選択 → 上部ツールバーの `︙`（三点）→「削除」** を実行:
   - 検索（空のラベル）ブロック ← 後で正しい検索に差し替えるため一旦消す
   - **最近の投稿**（「投稿が見つかりませんでした」と出ているやつ）
   - **最近のコメント**（「表示できるコメントはありません」と出ているやつ）
   - もし「新しい記事」「アーカイブ」「メタ情報」があれば全部削除

> 削除後に「スクロール広告用」アコーディオンが別途あるが、そちらはこのサイトでは不要なので **触らなくてよい**（アコーディオンを展開しないまま放置）。

#### 4-2. 追加するブロック

サイドバーウィジェット領域の **一番下の `+` ボタン** をクリック → ブロック検索で以下を追加:

1. **検索**（`/search` で検索） — 追加後、ラベルは空欄のままで OK
2. **カテゴリー**（`/category` または `/categories`） — 「ドロップダウンで表示」はチェック不要、「階層を表示」はチェック不要、「投稿数を表示」はチェック任意
3. **カスタム HTML**（`/html`） — 中身は [Step 5](#step-5-本体サイトへの導線ウィジェットを追加5-分) の HTML を貼り付け

#### 4-3. 保存

画面右上の **青い `更新` ボタン** をクリック。

### Step 5. 本体サイトへの導線ウィジェットを追加（5 分）

「カスタム HTML」または「テキスト」ウィジェットに以下を貼る。CSS は AFFINGER4 標準のスタイルに乗っかる形にし、コード追加は避ける（インライン style のみ許容）。

```html
<div style="background:#FFF8F0;border:1px solid #EDE5DA;border-radius:12px;padding:20px;text-align:center;">
  <p style="margin:0 0 12px;color:#3D3029;font-weight:bold;">
    無料で姓名判断を試す
  </p>
  <p style="margin:0 0 16px;color:#8A7D73;font-size:13px;line-height:1.6;">
    姓と名を入れるだけで<br>五格の運勢がすぐわかります
  </p>
  <a href="https://namae-studio.com/shindan.html"
     style="display:inline-block;background:#E8725C;color:#fff;padding:10px 20px;border-radius:9999px;text-decoration:none;font-weight:bold;">
    診断ページへ →
  </a>
</div>
```

ウィジェットタイトルは空欄推奨（見出しが重複しないように）。

---

### Step 6. カラーを親サイトに寄せる（8 分）

1. **外観 → カスタマイズ → 基本エリア設定（色/リンク色）** または **AFFINGER 管理 → 全体設定 → 基本カラー**
2. 以下を設定:

| 項目 | 値 |
|---|---|
| 基本リンク色 | `#E8725C` |
| リンクマウスオーバー色 | `#D05A46` |
| サイト背景色 | `#FFF8F0` |
| サイト全体の文字色 | `#3D3029` |
| ヘッダー背景色 | `#FFFFFF` |
| フッター背景色 | `#FFF8F0` |
| フッター文字色 | `#5C4F44` |

3. 記事タイトル・見出し系も同じ系統で揃える（`#3D3029` 基調、アクセントに `#E8725C`）
4. 「公開」で保存

> AFFINGER4 はカラー設定の項目数が多い。全項目は触らなくてよい。**明らかに浮いている色だけ** 直せば OK。

---

### Step 7. トップページの表示を整える（3 分）

記事ゼロの間は、「記事がありません」が目立たないように固定ページをトップに置くことも検討できる。ただし今回は **記事自動投稿が近く動く予定** なので、固定ページ化はせず、以下だけ対応:

1. **設定 → 表示設定**
2. 「1 ページに表示する最大投稿数」を **5** に（デフォルト 10 のまま空状態が悪目立ちしないように）
3. 保存

1. 別タブで `https://column.namae-studio.com/` をシークレットウィンドウで開く
2. 確認項目:

   - [ ] サイドバーが空ウィジェットだらけじゃないか
   - [ ] 「診断ページへ」ボタンが出ているか、クリックで `namae-studio.com/shindan.html` へ飛ぶか

   - [ ] モバイル表示でも崩れていないか（DevTools のモバイルエミュレータで確認）

## 🚨 記事投入開始時に必ず戻す TODO（忘れる未来を予防）

記事ゼロ期に「みっともない空表示」を隠すために一時的に消した機能がある。`ブログ記事作成スタジオ/wp_publisher` の自動投稿が動き始めるタイミング、あるいは最初の本記事が公開されたタイミングで **必ず以下を戻す or 対応する** こと。

### ① サイドバーにカテゴリーウィジェットを戻す

- **場所**: 外観 → ウィジェット → サイドバーウィジェット
- **操作**: `+` → 「カテゴリー」ブロックを追加
- **位置**: 「無料で姓名判断を試す」CTA の **上** 推奨（記事分類の導線を優先）
- **設定**: 投稿数を表示 ON（記事が増えてくると信頼感が出る）

### ② サイドバーにアーカイブウィジェット（任意）

- 月別アーカイブが欲しいなら同様に追加。SEO 的には無くても良い。

### ③ 投稿ページの SNS ボタン処理（Google+ 対策）

- **必須**（主様明示）
- AFFINGER4 管理 → SNS 設定 に「投稿ページの SNS ボタンを非表示にする」があるが、これを ON にすると全 SNS ボタンが消えてシェア性能が落ちる
- 対応オプション:
  - **案 A**: AddToAny 等の SNS シェアプラグインを導入して AFFINGER4 側のボタンは全部消す（推奨）
  - **案 B**: 子テーマ化して CSS で `.google-plus-btn` 等だけを `display:none`
- 判断は記事投入前に再検討

### ④ トップページの SNS ボタン非表示設定を見直し

- 現在: トップページの SNS ボタンを非表示 ON
- 記事が並び始めたら、個別記事カードにはシェアボタンが欲しくなる可能性あり。その場合は ③ で差し替えてから OFF に戻す

### ⑤ サイドバーの新着記事一覧の再表示（AFFINGER4 管理）

- **場所**: AFFINGER4 管理 → トップページの設定 → 新着記事セクション
- 現在: `☑ トップページのサイドバーの新着記事一覧を非表示にする` にチェック（記事ゼロ期の「新しい記事はありません」空表示を隠すため）
- **戻し方**: このチェックを外して save
- （下層ページ側も同時にチェックした場合は合わせて外す）
- 戻したら「NEW ENTRY」の見出し文言も日本語（例: 新着記事）に調整するか判断推奨

### ⑥ ヘッダーメニューの微調整（追加 CSS）

AFFINGER4 4.x のヘッダーメニューは `<nav class="smanone clearfix">` を `#headbox-bg` / `#gazou-wide` / `#st-menubox` / `#st-menuwide` で多重ラップしている（DevTools inspect で 2026-04-24 に特定）。

カスタマイザー → 追加 CSS パネルに以下の CSS を投入。子テーマ化までの暫定措置:

```css
/* AFFINGER4: ヘッダーメニューのグラデ背景を単色クリームに */
#headbox-bg,
#gazou-wide,
#st-menubox,
#st-menuwide,
nav.smanone {
  background: #FFF8F0 !important;
  background-image: none !important;
}

/* メニュー項目テキスト */
#st-menuwide a,
nav.smanone a {
  color: #3D3029 !important;
  background: transparent !important;
}

/* メニュー項目ホバー */
#st-menuwide a:hover,
nav.smanone a:hover {
  background: rgba(232, 114, 92, 0.12) !important;
  color: #E8725C !important;
}

/* 2 行折り返し緩和: PC時フォント・余白をタイト化 */
@media (min-width: 769px) {
  #st-menuwide a,
  nav.smanone a {
    font-size: 14px !important;
    padding: 12px 10px !important;
  }
}
```

**戻し方**: 子テーマ化して同等の CSS を子テーマ style.css に移したら、追加 CSS パネルから上記を削除する。

   - `☑ ヘッダー画像を全て非表示にする` → 巨大な AFFINGER4 プレースホルダーロゴ消滅

2. **AFFINGER 管理 → SNS 設定**
   - `☑ トップページのSNSボタンを非表示にする` → Twitter/Facebook/Google+/Pocket/はてブ/LINE 全消滅（トップのみ）
   - 投稿ページ側は **今回保留**（記事投入前に再判断、TODO として本プラン上部に明記）

3. **外観 → ウィジェット（ブロックエディタ）**
   - 削除: サイドバーウィジェット内の「最近の投稿」「最近のコメント」Heading ブロック残骸
   - 削除: スクロール広告用エリアに紛れていた「アーカイブ」「カテゴリー」ウィジェット（これが front-end に出ていた犯人）
   - 追加: サイドバーウィジェットに 検索ブロック＋カスタム HTML（CTA カード）
   - カテゴリーウィジェットは記事ゼロ期は撤去（記事投入時に戻す TODO 明記）

4. **AFFINGER 管理 → トップページの設定 → 新着記事**
   - `☑ トップページのサイドバーの新着記事一覧を非表示にする`
   - `☑ 下層ページのサイドバーの新着記事一覧を非表示にする`
   - → 「新しい記事はありません」の空表示が消滅

5. **外観 → カスタマイズ → 全体カラー設定（基本3色）**
   - キーカラー: `#E8725C`（テラコッタ）
   - メインカラー: `#6EC4A8`（セージ）
   - サブカラー: `#FFF8F0`（クリーム）
   - テキスト: `#3D3029`（ダークブラウン）
   - 「(1) 全体的に反映」で一括適用
   - → タイトル下に親サイト風グラデーションバー出現

6. **外観 → カスタマイズ → 基本エリア設定**
   - 背景色: `#FFF8F0`
   - ヘッダーエリア → 背景色: `#FFFFFF`
   - サイトタイトルとキャッチフレーズの文字色: `#3D3029`
   - フッターエリア → フッター文字色: `#5C4F44`
   - フッターエリア → 背景色: `#FFF8F0`
   - → サイト全体がクリーム基調の和モダン×ぬくもりに
